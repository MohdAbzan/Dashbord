# DataLens

A modern browser-based analytics workspace that turns CSV data into clear, decision-ready insights.

## Features

- CSV upload and drag & drop
- Automatic profiling
- KPI dashboard
- Metric trajectory visualization
- Data quality scan
- Missing and duplicate detection
- Searchable data explorer
- CSV export
- Automatic trend signals
- Light/dark mode
- Responsive glassmorphism UI
- Browser-only CSV processing
- GitHub Pages deployment

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## GitHub Pages

The repository includes `.github/workflows/deploy.yml`.

After pushing to the `main` branch, enable **Settings → Pages → Source → GitHub Actions**.

## Privacy

CSV processing happens in the browser. This project does not include a backend upload service.
